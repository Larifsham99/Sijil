# Penjana Sijil

Aplikasi web ringkas untuk menjana sijil tersuai secara beramai-ramai. Semuanya berjalan dalam pelayar, tiada pelayan atau pemasangan diperlukan.

## Cara guna

1. Buka `index.html` dalam pelayar (Chrome / Edge / Firefox). Pastikan folder `lib/` berada bersama fail ini.
2. **Maklumat**: isi perkara / nama program, tarikh, tempat dan awalan no. siri.
3. **Peserta**: tampal senarai dari Excel/Google Sheets (lajur: Nama, No K/P, Jawatan), import CSV, atau tambah seorang demi seorang.
4. **Teks**: ubah ayat, fon, saiz, warna dan kedudukan setiap teks. Kod `{nama}`, `{ic}`, `{jawatan}`, `{perkara}`, `{tarikh}`, `{tempat}`, `{bil}`, `{siri}` diganti secara automatik. `**teks**` untuk huruf tebal.
5. **Logo**: muat naik satu atau lebih logo; laras saiz, kelegapan dan kedudukan (atau jadikan tera air).
6. **Tandatangan**: muat naik tandatangan mudir (pilihan buang latar putih), tukar nama, jawatan, institusi, saiz dan kedudukan. Boleh tambah penandatangan kedua.
7. **Latar & Bingkai**: orientasi A4, gaya bingkai, warna, atau guna gambar latar sendiri.
8. Seret mana-mana elemen di pratonton untuk ubah kedudukan; anak panah papan kekunci untuk laras halus.
9. Eksport: **Muat Turun PDF** (semua dalam satu fail), **PDF Berasingan (ZIP)** (satu fail setiap peserta), atau **Cetak Semua**.

Kerja disimpan automatik dalam pelayar. Guna **Simpan Templat** / **Buka Templat** untuk simpan reka bentuk ke fail `.json` dan guna semula.

Fon dimuatkan dari Google Fonts (perlukan internet); tanpa internet, fon sistem akan digunakan.
